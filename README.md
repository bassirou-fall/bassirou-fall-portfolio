# Portfolio — Bassirou Fall

Site statique (HTML / CSS / JS), sans dépendance.

## À compléter
- **LinkedIn / WhatsApp** : renseigner `LIENS` en haut de `script.js` (les liens restent masqués tant qu'ils sont vides).
- **CV.pdf** : remplacer par la dernière version quand elle change.

## Fichiers
- `index.html` — contenu
- `style.css` — design (thème sombre + clair)
- `script.js` — menu mobile, thème, animations, copie de l'email, zoom du dashboard
- `photo.jpg`, `dashboard-global-superstore.jpg` — images optimisées
- `og-image.jpg` — image affichée quand on partage le lien (LinkedIn, WhatsApp…)
